END-TO-END CAPABILITIES

One product, three trustworthy surfaces.

01

Telegram-first

Class linking, natural-language assignments, acknowledgements, progress, blockers, text/file/photo submissions, status, and feedback delivery.

02

Teacher operations

Scoped classes, natural-language creation, deadline changes, risk summaries, reminder control, submission review, and feedback.

03

Student clarity

Only the authenticated student’s work, deadlines, progress, submissions, status, and feedback—never a classmate’s data.

04

Validated AI boundary

OpenAI structured output can interpret language and phrase messages. Deterministic code owns authorization, transitions, IDs, and delivery policy.

05

Persistent automation

Restart-safe reminder records distinguish blocked, silent, due-soon, and overdue students with daily anti-spam deduplication.

06

Operational safety

Signed sessions, PBKDF2 passwords, CSRF protection, SQLite foreign keys/WAL, safe uploads, request IDs, and activity logs.

ARCHITECTURE

Model-assisted.
Deterministically safe.

Transport adapters delegate to shared domain services. Every supplied ID passes server-side scope checks. Every student state change passes one central transition map. Model output is validated before it can become domain input.
